# src/components — shared UI

Pieces used by more than one page. A page's own pieces live beside it instead
(in an `_folder`).

| Component | What it is |
|---|---|
| `ErrorScreen` | "Something went wrong" / "Page not found": the brand, a sentence, Try again and home |
| `FloatingSave` | the one Save button per page: grey until something changes, keeps changes if a save fails |
| `Field` | a form field's label, hint and input |
| `icons` | small line icons (WhatsApp, email, RSVP, edit…) |
| `BrandLogo` | the One Tap Invites logo |
| `MadeWith` | the line at the foot of guest pages, with the feedback link |
| `GuestFeedback` | the "Questions or feedback?" form guests can send us |
| `IndicKeyboard` | on-screen Gujarati/Hindi keyboard for the card wording page |
| `MaskUpload` | turns an uploaded symbol or icon into a shape drawn in the theme's colour |
| `MotifSvg` | draws a card motif on the website, in the theme's colours |
| `ImageGuard` | makes the couple's photos hard to save from guest pages |
| `PageLoading` | the ripple shown while a signed-in page loads |
| `SideNames` | the families' first names, for client pieces deep in a page |
